# Mechanical Engineering Portfolio

A static HTML/CSS portfolio for Saw Hla Nwe (Hendrika), built from the supplied CV and CAD portfolio.

## Files
- `index.html` — website content
- `style.css` — layout and styling
- `assets/` — original images extracted from the CAD portfolio presentation
- `CV.docx` — downloadable CV

## Preview
Open `index.html` in a browser. No build tools or JavaScript required. The fonts load from Google Fonts; fallback fonts are provided.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, e.g. `engineering-portfolio`.
2. Upload **the contents of this folder** (not the ZIP), keeping `index.html` at the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**; save.
5. Visit `https://YOUR-USERNAME.github.io/engineering-portfolio/` after deployment.
